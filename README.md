# Fardin Akhlaghian Tab

**Associate Professor | University of Kurdistan, Iran**

Machine Learning • Deep Learning • Computer Vision • Matrix Factorization

## About Me

I am an Associate Professor of Computer Engineering at the University of Kurdistan, Iran.

My research focuses on machine learning, computer vision, data mining, and advanced matrix factorization techniques, with particular emphasis on representation learning and intelligent data analysis.

## Research Interests

- Machine Learning and Deep Learning
- Computer Vision and Image Processing
- Nonnegative Matrix Factorization
- Representation Learning
- Feature Selection and Dimensionality Reduction
- Graph Clustering and Network Analysis
- Multi-View Learning

## Research Group

### Algebraic Machine Learning (AML) Team

I supervise the **Algebraic Machine Learning (AML) Team**, part of the Representation Learning Lab at the University of Kurdistan.

Our research focuses on representation learning, robust machine learning, matrix factorization, and complex network analysis.

**Website:** [AML Research Team](https://amlteams.github.io/)
